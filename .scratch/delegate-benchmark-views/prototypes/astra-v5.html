Selection, zoom and ranking rules

Click a model chip, line, plot dot or table row to show that model on that harness with all efforts. Shift-click a model chip, line or row to add or remove a model. Plot dots use Shift-click to add or remove efforts. Table effort dots and effort chips select one effort on click, and toggle it on Shift-click. On touch, enable “Add/remove” for the same behavior. Clear restores all in its group. A direct model selection admits its harness.

Wheel or pinch zooms about the pointer; drag pans; Shift-drag draws a box. Double-click or Reset restores the view. Expand opens a plot at full width. Axis ticks and collision-tested labels update at every zoom.

Ranges are real scores across displayed efforts. Percentiles compare against the board’s complete population. Classification score is the mean percentile over measured boards, with n/N coverage; ~ means thin evidence. Only carried lanes receive ranks, tiers and leader labels. Tiers preserve current carried-tier counts; ties share rank and tier. Filters never change the ranking population. Relative cost is the geometric mean of cost / board median cost, a proxy across different cost bases. Favoured effort is the cheapest measured effort within five percentile points of the model’s best. Overall is a reference-only composite.

Reference visibility is independent of lane selection. Missing reference harnesses are labelled “harness unspecified”. Missing versions remain explicitly unknown. Shared model evidence does not imply a separate measured run on each catalog harness.
